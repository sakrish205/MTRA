# Reference set 01 — flat plate, serpentine raster

This project is **constructed**, not measured from a real cell. Its purpose is to
give every report number something to be checked against: the geometry, the
program and the expected measurements all come from one specification, so a
regression shows up as a changed value instead of a plausible-looking report.

Generated by `tests/fixtures/synthetic.py` (`build_project`).

## What is in the box

| File | What it is |
| --- | --- |
| `project.json` | One pair (`plate`), units `mm`, identity transform `part -> world` declared |
| `input/meshes/plate.stl` | Closed subdivided box, 200 x 300 x 5 mm, top face at z = 5 mm |
| `input/robot_programs/raster.ls` | FANUC LS, 9 serpentine passes, 29 motion instructions |

The manifest deliberately declares **no tool**. Tool axes are taken from the
program's W/P/R instead; with W = P = R = 0 the tool points along world **-Z**.

## Expected headline measurements

Exact values, because they are properties of the construction:

- **A3** TCP-to-surface distance: median 15.0 mm, zero spread.
- **A4** tool-axis intersections: 100 % hit fraction, all on the plane z = 5 mm.
- **A5** nearest-point vs ray-intersection disagreement: < 1e-6 mm (flat surface).
- **B1** mean path axis `[1, 0, 0]`, bearing 0 degrees, axial stability 1.0.
- **B2** per-pass bearing 0 degrees for all 9 passes, including reversed passes.
- **B4** surface normal `[0, 0, 1]`, mean 90 degrees, plane tilt 0.
- **B6** path/border difference 90 degrees.
- **C1 = C2 = C3 = J3** 25.0 mm over 8 pass pairs.
- **E2**, **I2** zero (no curvature, no normal-to-tool deviation).
- **I5** 15.0 mm.
- **J2** `alternating`, 8 reversed pairs.

## Expected absences

These are deliberate and must stay visible:

- **A2** `no_independent_measurement` — registration error needs a fiducial or a
  fit, neither supplied in Phase 1.
- **E6** `degenerate_geometry` — a flat plane has no unique curvature direction.
- **D9, F1, G1, and all other phase > 1 parameters** `out_of_phase_scope`.

The 112-row catalogue resolves to **61 values / 51 absences** for this input.
That split is a property of the current Phase 1 scope, not of the part.

## What this reference set does not prove

- It is not real production data; it cannot validate the FANUC grammar against a
  controller, the tool definition convention, or any paint process behaviour.
- No units other than millimetres are exercised; `test_units.py` covers the
  conversion arithmetic.
- The mesh is an idealised closed solid; tessellation artefacts of scanned tooling
  are not represented.
