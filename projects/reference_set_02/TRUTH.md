# Reference set 02 — cylinder, five axial passes

This project exists to check the measurements that are degenerate on a flat plate:
surface curvature, geodesic versus TCP-space spacing, and the surface normal
against the tool axis.

Generated by `tests/fixtures/synthetic.py` (`build_cylinder_project`).

## What is in the box

| File | What it is |
| --- | --- |
| `project.json` | One pair (`cylinder`), units `mm`, identity transform `part -> world` |
| `input/meshes/cylinder.stl` | Closed procedural cylinder, radius 40 mm, height 160 mm |
| `input/robot_programs/cylinder.ls` | FANUC LS, 5 axial passes at -40, -20, 0, 20, 40 degrees |

Each pass is a straight vertical line at TCP radius 55 mm, with W/P/R chosen so
the tool axis points radially inward. The manifest declares no tool axis; the
inward attitude comes from the program alone.

## Expected headline measurements

- **C1 = C2 = J3** 19.1013 mm — straight-line (chord) spacing in TCP space.
- **C3** 13.732 mm — first-order surface arc, within 3 % of the analytic
  13.9626 mm. `max_snap_offset_mm` is reported alongside so the endpoint
  correction is auditable.
- **A3** median 15.008 mm, maximum 15.047 mm — the nearest-surface distance from
  a TCP on a chord to the cylinder is slightly more than the radial standoff.
- **A5** non-zero: nearest surface point and tool-axis intersection separate on a
  curved surface. This is the divergence the flat fixture cannot show.
- **B1** mean axis `[0, 0, 1]`, bearing `null`, elevation 90 degrees. An axial
  vertical pass has no planar bearing; reporting 0 degrees would be an invention.
- **B2** `strokes_with_bearing` 0 and `bearing_stats` null for the same reason.
- **E2** median about 0.0328 /mm — discrete mean curvature overestimates 1/R on a
  10 mm median edge mesh; the reported `resolution_ratio` makes that visible.
- **I2** spread from 0 to about 0.625 degrees as the radial tool axis is compared
  with per-sample surface normals.
- **I5** mean 15.026 mm.
- **J2** `alternating`, 4 reversed pairs.

## Expected absences

- **B6** `degenerate_geometry` — the dominant path direction is vertical, so there
  is no planar path bearing to compare with a border direction.
- **A2, E6, D9, F1, G1** as in `reference_set_01`.
- The catalogue again resolves to **61 values / 51 absences**.

## Tolerance policy

C1/C2/J3 are compared to the chord at `rel=1e-3`. C3 is compared to the analytic
arc at `rel=3 %` because the endpoint correction is first order, not exact. E2 is
compared to 1/R at `rel=60 %` to assert magnitude and ordering only; its absolute
value depends on the tessellation, which is reported rather than assumed away.
